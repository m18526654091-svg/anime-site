## Action 分类

| 类别 | 条件 | Action |
|---|---|---|
| **A** | CTR < 1% 且 Impressions > 500 | **优化 title**（Phase 9/19 模板规则） |
| **B** | Position 5-20 | **改善内容 / 内链**（Anime Information/About/Why 模块 + 相关页内链） |
| **C** | 高 Impressions 无 Clicks | **改善搜索意图匹配**（title/description 更贴合 query） |
| **D** | 无 Impressions | **等待或重新评估**（页面价值/索引状态） |

## 处理流程
1. 每周从 GSC 导出 Performance 数据填入上表
2. 按 Action A-D 分类标记
3. 每类只处理明确问题页（不批量强行修改）
4. 记录 before/after 供下周对比

## 数据原则
- 无 GSC 数据前不执行任何优化动作（本阶段原则：所有优化基于真实数据）
