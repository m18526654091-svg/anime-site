# AnimeHub Phase 23 — Authority Execution Plan

> 生成于 2026-08-29 · 仅策略，不执行（部署+GSC 确认后启动）

## Allowed（真实、非 spam）

### 1. Reddit Participation
- 参与 r/anime、r/Animesuggest 等自然讨论
- **时机**：用户主动询问 watch order / best {genre} / anime like X
- **方式**：提供真实有用的回答，自然提及 AnimeHub 资源（watch-order 页、best 列表）
- **频率**：极低（每周 ≤2-3 条真实参与），非自荐 spam
- **合规**：遵守 subreddit 规则，避免 90% 推广/10% 参与 的失衡

### 2. Anime Community Discussion
- Discord/社区：作为动漫资料参考被引用（不主动推）
- 论坛：在有价值讨论中提供数据型回答（如 franchise 顺序）

### 3. Social Sharing
- 未来可分享：franchise 顺序图、季度新番表（可引用图表）
- 平台：Twitter/X、Pinterest（动漫视觉内容）

### 4. Useful Resources
- watch-order 页、best-anime 列表、anime-series 目录 = 天然可引用资源
- 作为"动漫数据库"自然被其他资源站引用

## Forbidden
- ❌ 购买 backlinks / PBN / 链接农场
- ❌ 论坛/评论批量发链接
- ❌ 伪装推广
- ❌ 内容农场互链

## 启动条件
1. 生产部署全部 pending release
2. GSC 确认索引正常（indexed ≥ 60%）
3. 内容质量季度复检
4. 从低频真实参与开始，观察效果
