# AnimeHub Phase 20 — External Authority Plan

> 生成于 2026-08-29 · 仅策略文档，不执行（禁止买链接/垃圾外链）

## 原则
- **不购买链接、不参与链接交易、不垃圾外链**
- 一切行动以"内容本身值得被引用"为基础
- 等待生产部署 + GSC 数据后启动

## 1. Anime Community Sharing（内容可分享性）
- Detail 页已含：完整信息 + Similar + Watch Order + Franchise → 天然可引用
- 待启动：为 Top 100 页面准备"可引用锚点"（如 franchise 目录、watch order 页面已是标准引用对象）

## 2. Reddit Participation Strategy（被动策略）
- **不做自荐 spam**；仅在 r/Anime 等相关 subreddit 的自然讨论中，当用户询问 watch order / best {genre} 时，由**非关联账号**自然提及（合规边界内）
- 价值锚点：watch-order 页（解决真实问题）、best-anime 列表（推荐请求）
- **原则**：内容先于推广，频率极低，避免社区反感

## 3. Social Content
- 未来可制作：franchise 观看顺序图、季度新番一览（可分享图表）
- 平台：Twitter/X、Pinterest（动漫图集）、YouTube Shorts（候补）

## 4. Natural Backlinks
- 现有价值：watch-order 顺序页 / best-anime 列表 / anime-series 目录 是自然引用对象
- 数据引用：无第三方数据可引用（全部自有 DB），不强求
- 目录/资源页：若其他动漫资源站愿意收录为"动漫数据库"链接，属自然外链（不主动购买）

## 5. 启动条件
1. 生产部署 Phase 10-19 全部代码
2. GSC 数据接入确认索引正常
3. 内容质量季度复检（无低质页）
4. 社区参与从 Phase 20 后按周度低频启动

## 禁止项
- ❌ 购买外链 / PBN / 链接农场
- ❌ 论坛/评论区批量发链接
- ❌ 伪装链接内容（付费软文不作披露）
